El SDK de Go se distribuye como un módulo Go estándar. No hay registry
separado — `go get` baja el código directo de GitHub. El SDK provee una
función tipada por cada endpoint de OrigoID, sigue patrones Go
idiomáticos (`context.Context`, structs exportados, errores explícitos),
y embebe la base URL de producción.

## Instalación

```bash
go get github.com/origoid/sdk-go@v0.1.0
```

O agrega a `go.mod`:

```go
require github.com/origoid/sdk-go v0.1.0
```

Luego corre `go mod tidy`. Código en
[github.com/origoid/sdk-go](https://github.com/origoid/sdk-go).

Requiere Go **1.21 o más reciente**.

## Inicializa el cliente

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/origoid/sdk-go/client"
    "github.com/origoid/sdk-go/option"
)

func main() {
    c := client.NewClient(
        option.WithAPIKey(os.Getenv("ORIGOID_API_KEY")),
    )
    _ = c
    fmt.Println("client ready")
}
```

Ese es todo el setup. La base URL `https://api.origoid.com` está
**embebida en el SDK** — no requiere `WithBaseURL` para producción. Sólo
override para staging o dev:

```go
c := client.NewClient(
    option.WithAPIKey(os.Getenv("ORIGOID_API_KEY")),
    option.WithBaseURL("https://staging-api.origoid.com"),
)
```

Nunca hardcodees la key. Léela de `os.Getenv`, [`viper`](https://github.com/spf13/viper),
o tu secrets backend.

## Tu primera llamada

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    origoid "github.com/origoid/sdk-go"
    "github.com/origoid/sdk-go/client"
    "github.com/origoid/sdk-go/option"
)

func main() {
    c := client.NewClient(
        option.WithAPIKey(os.Getenv("ORIGOID_API_KEY")),
    )

    env, err := c.Renapo.ValidateCurp(
        context.Background(),
        &origoid.ValidateCurpRequest{Curp: "PELJ900101HDFRRN09"},
    )
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(env.Status)          // "OK"
    fmt.Println(env.Type)            // "SUCCESS", "CURP_DECEASED", ...
    fmt.Println(env.TransactionId)   // uuid
    fmt.Println(env.Data)            // map[string]any con registro RENAPO
}
```

Cada método devuelve `(*origoid.Envelope, error)`. La shape del envelope
es `{ Status, Type, Message, Data, TransactionId, ProcessedAt, Billable,
Errors }`. Ver [Envelope de respuesta](/es/envelope) para el contrato.

## Métodos por recurso

El cliente agrupa operaciones por dominio regulatorio. Los nombres de
método replican el `operationId` del OpenAPI en PascalCase exportado de Go.

### `c.Authentication`

```go
c.Authentication.IssueToken(ctx, &origoid.IssueTokenRequest{ExpireAfter: 1800})
```

### `c.Renapo`

```go
c.Renapo.ValidateCurp(ctx, &origoid.ValidateCurpRequest{
    Curp: "PELJ900101HDFRRN09",
})

c.Renapo.LookupCurp(ctx, &origoid.LookupCurpRequest{
    GivenNames:     "JUAN",
    FirstSurname:   "PEREZ",
    SecondSurname:  origoid.String("LOPEZ"),
    DateOfBirth:    "1990-01-01",
    Gender:         origoid.LookupCurpRequestGenderH,
    BirthStateCode: "DF",
})
```

`origoid.String(...)` es un helper para campos string opcionales (Go no
tiene `Option<T>`; la opcionalidad se modela con punteros).

### `c.Sat`

```go
c.Sat.ValidateRfc(ctx, &origoid.ValidateRfcRequest{Rfc: "PEZJ811011KI1"})

c.Sat.ExtractCsf(ctx, map[string]any{
    "rfc": "PEZJ811011KI1",
    "cif": "17060597619",
})

c.Sat.ValidateCfdi(ctx, map[string]any{
    "uuid":        "7C8BD4EA-AE86-4CB5-88B8-C6E61E988A8B",
    "rfcEmisor":   "PEZJ811011KI1",
    "rfcReceptor": "EMP170623KI3",
    "total":       "999999.99",
})
```

`ExtractCsf` y `ValidateCfdi` aceptan `map[string]any` porque los
schemas usan `oneOf` — identificadores directos o modo documento.

### `c.Imss`

```go
c.Imss.LookupNss(ctx, &origoid.LookupNssRequest{Curp: "PELJ900101HDFRRN09"})

c.Imss.GetEmploymentStatus(ctx, &origoid.GetEmploymentStatusRequest{
    Curp: "PELJ900101HDFRRN09",
    Nss:  "92038109713",
})
```

### `c.Ine`

```go
c.Ine.ValidateVoterList(ctx, map[string]any{
    "cic":               "123456789",
    "citizenIdentifier": "987654321",
})

c.Ine.ExtractVoterIdData(ctx, &origoid.ExtractVoterIdDataRequest{

c.Ine.ExtractQrData(ctx, &origoid.ExtractQrDataRequest{
```

### `c.Compliance`

```go

c.Compliance.SearchSat69B(ctx, map[string]any{"rfc": "PEZJ811011KI1"})
```

### `c.Biometrics`


## Manejo de errores

El SDK distingue entre **errores de negocio** (vienen dentro del
envelope) y **errores de transporte** (devueltos como `error` no nulo).

### Errores de negocio — inspecciona el envelope

Para cualquier HTTP 200, incluyendo `INVALID_REQUEST`, el SDK devuelve
un `*Envelope` normal. Revisa `Status` y `Type`:

```go
env, err := c.Renapo.ValidateCurp(ctx, &origoid.ValidateCurpRequest{Curp: "BAD"})
if err != nil {
    log.Fatal(err)
}

switch env.Type {
case "SUCCESS":
    // happy path
case "CURP_DECEASED":
    // resultado de negocio
case "CURP_NOT_FOUND":
    // sin match
case "INVALID_REQUEST":
    for _, e := range env.Errors {
        fmt.Printf("  %s: %s — %s\n", e.Field, e.Code, e.Message)
    }
}
```

### Errores de transporte — `error` no nulo

Para `401`, `429`, fallas de red, el SDK devuelve un error tipado:

```go
import "errors"

env, err := c.Renapo.ValidateCurp(ctx, req)
if err != nil {
    var unauth *origoid.UnauthorizedError
    var rl *origoid.TooManyRequestsError
    switch {
    case errors.As(err, &unauth):
        // 401
    case errors.As(err, &rl):
        // 429 — lee rl.Body para el envelope de rate-limit
    default:
        // red / timeout / inesperado
        log.Fatal(err)
    }
}
```

## Configuración por llamada

Usa helpers `option.With*` como argumentos adicionales:

```go
import "time"

env, err := c.Ine.ValidateVoterList(
    ctx,
    map[string]any{"cic": "123456789", "citizenIdentifier": "987654321"},
    option.WithRequestTimeout(120 * time.Second),
    option.WithMaxAttempts(3),
)
```

Pasa un `context.Context` para respetar deadlines o cancelaciones del
caller; el SDK respeta `ctx.Done()` y aborta requests en vuelo.

## Punteros para campos opcionales

Go no tiene `Option<T>`, así que los campos opcionales en structs de
request son tipos puntero. El SDK expone helpers para hacerlo menos
verboso:

```go
origoid.String("valor opcional")  // *string
origoid.Int(42)                   // *int
origoid.Bool(true)                // *bool
```

Para enums:

```go
origoid.MatchFacesRequestDocumentTypeIne.Ptr()
```
