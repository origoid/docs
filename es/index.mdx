## Qué es OrigoID

OrigoID es la **infraestructura de validación de identidad y cumplimiento** para México. No somos un marketplace de APIs desconectadas — somos una plataforma opinionada que estandariza las respuestas de cada fuente oficial en un contrato JSON limpio y predecible.

Operamos como un túnel, no como una bóveda: validamos contra RENAPO, INE, IMSS, SAT, OFAC y PEPs en milisegundos y devolvemos los datos estructurados que tu producto necesita. **No almacenamos la información personal que validamos**. Los datos de tus clientes se quedan donde corresponde — contigo y con las autoridades oficiales.

### Por qué los equipos eligen OrigoID

- **Un solo contrato para cada fuente.** Mismo envelope, misma autenticación, mismo manejo de errores en CURP, RFC, CFDI, INE, IMSS, OFAC y PEPs.
- **Integración en minutos, no en semanas.** API RESTful con ejemplos copy-paste en 7 lenguajes y un contrato bilingüe estricto (superficie API en inglés, campos passthrough preservados en español según el regulador).
- **Hecha para industrias reguladas.** Compatible con LFPDPPP y diseñada para apoyar las obligaciones CNBV de nuestros clientes, con TLS 1.3 de extremo a extremo e infraestructura aislada.
- **Soberanía de datos por diseño.** Sin almacenamiento persistente de PII (Información Personal Identificable) en respuestas exitosas. Sólo metadata operativa — para facturación y auditoría.
- **Resultados honestos.** Códigos `type` estables para cada resultado, sin scores opacos, sin sorpresas en tus switch statements.

## Cobertura mexicana

| Fuente | Capacidad |
|---|---|
| RENAPO | CURP validar, buscar |
| INE | Lista Nominal, OCR Voter ID, QR |
| IMSS | NSS lookup, estatus laboral |
| SAT | RFC, CSF, CFDI, listas 69 y 69-B |
| OFAC + PEPs | Sanciones globales + PEPs MX |
| Biometría | Face match 1:1, liveness |
