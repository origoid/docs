Esta página consolida los catálogos de códigos estables que aparecen dentro de las respuestas de varios endpoints de OrigoID. Estos códigos no cambian entre versiones — puedes confiar en ellos para tu lógica de negocio.

# Catálogos

#### 1. Estado de CURP (`statusCurp`)

Código de estado devuelto por RENAPO dentro de `personalInfo.statusCurp` y campos similares.

| `statusCurp` | Estado | Descripción |
| :--- | :--- | :--- |
| `AN` | Activo | Alta normal. Vigente y al corriente. |
| `AH` | Activo | Alta con homonimia. Los primeros 16 caracteres coinciden con otra CURP. |
| `RCC` | Activo | Registro con cambio que afecta CURP. Corrección de datos modificó la clave. |
| `RCN` | Activo | Cambio que no afecta CURP. Corrección menor de datos. |
| `BAP` | Inactivo | Baja por documento apócrifo. |
| `BSU` | Inactivo | Baja sin uso. Requiere reactivación en módulo RENAPO. |
| `BD` | Inactivo | Baja por defunción. |
| `BDM` | Inactivo | Baja administrativa. |
| `BDP` | Inactivo | Baja por adopción. |
| `BJD` | Inactivo | Baja judicial. |

#### 6. Estado SAT Artículo 69-B (`complianceDetails.status`)

El endpoint SAT 69-B siempre devuelve `listType: SAT_69B`. El estado granular vive en `complianceDetails.status`:

| `status` | Descripción | Nivel de Riesgo |
| :--- | :--- | :--- |
| `PRESUNTO` | Actualmente bajo investigación por operaciones simuladas (EFOS) | ALTO |
| `DEFINITIVO` | Empresa fantasma / EFOS confirmada | CRÍTICO |
| `DESVIRTUADO` | Investigada pero demostró su inocencia | BAJO |
| `SENTENCIA_FAVORABLE` | Ganó en corte / absuelta por fallo judicial | BAJO |

#### 9. Efecto CFDI (`effect`)

Propósito fiscal de la factura según la clasificación SAT. Cada CFDI tiene exactamente un efecto.

| `effect` | Código SAT | Descripción |
| :--- | :--- | :--- |
| `INCOME` | I (Ingreso) | Factura de venta / ingreso. El emisor recibió pago por bienes o servicios. |
| `EXPENSE` | E (Egreso) | Devolución, nota de crédito o descuento. Revierte o reduce una factura de ingreso previa. |
| `TRANSPORT` | T (Traslado) | Comprobante de traslado de bienes (Carta Porte). No refleja venta, solo movimiento de mercancía. |
| `PAYROLL` | N (Nómina) | Recibo de nómina emitido por un empleador a un empleado. |
| `PAYMENT` | P (Pago) | Complemento de recibo de pago (REP) para facturas pagadas en parcialidades (PPD). |

#### 10. Estado CFDI (`status`)

Estado fiscal actual del CFDI según el servicio de verificación SAT.

| `status` | Descripción |
| :--- | :--- |
| `VALID` | Vigente. El CFDI está actualizado y es fiscalmente válido. |
| `CANCELED` | Cancelada. El CFDI ha sido cancelado y ya no es fiscalmente válido. |

#### 11. Estado de cancelación CFDI (`cancellationStatus`)

Refleja las reglas de cancelación SAT 2022 ("cancelación con aceptación"), que requieren consentimiento del receptor en algunos escenarios.

| `cancellationStatus` | Descripción |
| :--- | :--- |
| `NOT_CANCELABLE` | No puede cancelarse (ej. complementos de pago, recibos de nómina o facturas vinculadas a otros CFDIs activos). |
| `CANCELABLE_WITHOUT_ACCEPTANCE` | El emisor puede cancelar unilateralmente (montos pequeños, correcciones de nómina, etc.). |
| `CANCELABLE_WITH_ACCEPTANCE` | El emisor puede solicitar cancelación, pero el receptor debe aceptarla dentro de 72 horas. |
| `CANCELED_WITHOUT_ACCEPTANCE` | Ya cancelada; no se requirió aceptación. |
| `CANCELED_WITH_ACCEPTANCE` | Ya cancelada; el receptor aprobó la cancelación. |
