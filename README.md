# OrigoID API documentation

Source of [docs.origoid.com](https://docs.origoid.com) — the reference for the OrigoID API, an identity verification and compliance API for Mexico: CURP (RENAPO), INE voter list (Lista Nominal) and INE OCR, RFC, tax status certificate (CSF) and CFDI at SAT, NSS at IMSS, ISSSTE records, OFAC / PEPs / SAT 69 and 69-B screening, proof of address extraction, email validation and face match. Zero data retention.

- API reference (OpenAPI): https://docs.origoid.com/en/api-reference · https://docs.origoid.com/es/api-reference
- SDKs: [TypeScript/Node](https://github.com/origoid/sdk-node) · [Python](https://github.com/origoid/sdk-python) · [Go](https://github.com/origoid/sdk-go) · [MCP server](https://github.com/origoid/mcp-server) · [Postman](https://github.com/origoid/postman)
- Status: https://status.origoid.com · Support: support@origoid.com
